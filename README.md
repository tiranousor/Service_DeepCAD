
# DeepCAD: Генерация 3D-моделей на основе CAD-команд

**DeepCAD** — это генеративная нейросетевая модель, которая восстанавливает и синтезирует трёхмерные CAD-объекты на основе последовательностей команд инженерного проектирования. Модель имитирует работу конструктора в CAD-среде и позволяет воспроизводить логическую структуру объектов, включая профиль, экструзии и параметры геометрии.

В рамках данной реализации разработан сервис, объединяющий нейросетевую часть (Autoencoder + Latent WGAN) с веб-интерфейсом на FastAPI и встроенной поддержкой экспорта в STEP через OpenCASCADE. Сервис позволяет как восстанавливать CAD-модели по заданным входным данным, так и генерировать новые трёхмерные объекты.

## Выбор оптимальных гиперпараметров

Для повышения качества генерации были проведены эксперименты с различными архитектурными и обучающими параметрами. Целью являлось улучшение метрик генерации (COV-CD, MMD-CD, JSD), обеспечивающих оценку достоверности и разнообразия создаваемых моделей.

### Базовая конфигурация

Оригинальная реализация DeepCAD включала 4 слоя трансформера, размерность эмбеддингов 256, обучение в течение 1000 эпох без аугментации. Обучение проходило в течение 15 дней. Результаты базовой модели:

- **COV-CD** = 0.781  
- **MMD-CD** = 0.0145  
- **JSD** = 0.0376

### Промежуточные эксперименты

- При уменьшении глубины модели (до 3 слоёв) и снижении размерности эмбеддингов до 192 удалось ускорить обучение до 7 дней и повысить покрытие (**COV-CD** = 0.800), однако точность снизилась (JSD = 0.0507).
- Усиление регуляризации за счёт увеличения dropout до 0.3 привело к переупрощению модели и ухудшению всех метрик.
- Попытка усложнить архитектуру (5 слоёв, `d_model = 320`, `dim_z = 384`) увеличила время обучения до 9 дней, но не привела к улучшению качества (JSD = 0.0412).

### Финальная конфигурация

Была выбрана сбалансированная конфигурация: 3 слоя в трансформере, размерность 256, dropout 0.2, `loss_args_weight = 2.5`, learning rate 3e-4, warmup 1500 шагов и включённая аугментация. Эта модель обучалась 4 дня и показала лучшие результаты:

- **COV-CD** = **0.808**  
- **MMD-CD** = **0.0142**  
- **JSD** = **0.0343**

Она и была интегрирована в текущую версию сервиса.

## Как запустить проект

### Технологии

- **Python 3.8+**
- **FastAPI**
- **PyTorch**
- **OpenCASCADE**
- **Docker**

### 1. Установка Docker

Убедитесь, что у вас установлен [Docker](https://docs.docker.com/get-docker/) и [Docker Compose](https://docs.docker.com/compose/).

### 2. Клонирование репозитория

```bash
git clone https://github.com/tiranousor/Service_DeepCAD.git
cd Service_DeepCAD
```

### 3. Запуск сервиса

```bash
docker-compose up -d
```

Контейнер автоматически поднимет все необходимые компоненты в фоновом режиме.

### 4. Интерфейс

Документация и тестирование доступно по адресу:  
**http://localhost:8000/docs**

### 5. Остановка

```bash
docker-compose down
```

## Доступные эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/convert` | Восстановление CAD-модели по входному JSON с использованием DeepCAD. |
| `GET`  | `/generate_random` | Генерация одной случайной CAD-модели через латентное пространство, используя WGAN + Autoencoder. |
| `GET`  | `/generate_random_batch` | Пакетная генерация CAD-моделей с фильтрацией по минимальному размеру (в КБ) и возвратом подходящих вариантов. |
